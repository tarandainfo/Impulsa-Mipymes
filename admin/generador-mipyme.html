Generador de perfil de Mipyme

Herramienta interna solo para el administrador de Infonegocios. Completá los datos, copiá el código generado y pegalo en js/mipymes-data.js, dentro del array MIPYMES_DATA.

Esta página no guarda ni publica nada por sí sola. Es solo un generador de texto. Para que el perfil aparezca en la web real hay que pegar el código en el archivo y subir los cambios al repositorio (git add / commit / push) o volver a subir la carpeta al hosting.
